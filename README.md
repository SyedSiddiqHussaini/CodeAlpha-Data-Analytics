# CodeAlpha – Data Analytics Internship
This repository contains the projects I completed during my **Data Analytics Internship at CodeAlpha**.
The projects demonstrate practical applications of Python in web scraping, exploratory data analysis, data cleaning, and data visualization using real-world datasets.

## 📂 Internship Tasks
### 1. Web Scraping

**Objective:** Extract structured information from a website using Python.

**Tools & Libraries:**
* Python
* Requests
* BeautifulSoup
* CSV

**Work Completed:**

* Extracted quotes and author names from Quotes to Scrape.
* Parsed website content using BeautifulSoup.
* Stored the extracted information in a CSV file.
[View Task 1 – Web Scraping](./Task%201%20-%20Web%20Scraping/)

### 2. Exploratory Data Analysis (EDA)
**Objective:** Explore a World Bank indicators dataset to understand its structure, identify data quality issues, and examine patterns.

**Tools & Libraries:**
* Python
* Pandas
* Matplotlib
* Seaborn

**Work Completed:**
* Loaded and explored the dataset.
* Examined dataset dimensions and data types.
* Identified missing values.
* Created visualizations to explore GDP, life expectancy, remittances, and correlations between selected indicators.

[View Task 2 – Exploratory Data Analysis](./Task%202%20-%20Exploratory%20Data%20Analysis%20%28EDA%29/)

### 3. Data Visualization
**Objective:** Communicate patterns and trends in global remittance data through visualizations.

**Tools & Libraries:**
* Python
* Pandas
* Matplotlib
* Seaborn

**Work Completed:**
* Checked and removed duplicate records.
* Examined missing values.
* Analyzed global remittance trends.
* Compared remittances across countries, regions, and income groups.
* Explored GDP and remittances per capita.
* Created correlation heatmaps and box plots for outlier exploration.

[View Task 3 – Data Visualization](./Task%203%20-%20Data-Visualization/)
