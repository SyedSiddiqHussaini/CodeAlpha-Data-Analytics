Global Remittances & Migration Data Visualization (2000–2023)
-> Overview
This project focuses on transforming raw World Bank remittance and migration data into meaningful visualizations using Python.
The objective is to uncover trends, patterns, and relationships within the data and communicate findings through clear and impactful visualizations.

-> Dataset
Dataset: Global Remittances & Migration Dataset (2000–2023)
File:
* worldbank_indicators.csv

Dataset contains:

* Remittances Received
* Remittances Paid
* GDP Indicators
* Population Statistics
* Migration Indicators
* Income Group Information
* Regional Information

-> Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn

-> Visualizations Created

-> 1. Global Remittances Trend
Shows how remittance inflows evolved over time.

-> 2. Top 10 Countries by Remittances Received
Identifies leading remittance-receiving countries.

-> 3. Remittances by Region
Compares remittance inflows across global regions.

-> 4. Income Group Analysis
Analyzes remittance distribution across income groups.

-> 5. GDP vs Remittances
Examines relationship between economic development and remittance inflows.

-> 6. Correlation Heatmap
Displays correlations among numerical indicators.

-> 7. Outlier Detection
Highlights unusual observations in remittance data.

-> Key Insights

* Global remittances show significant long-term growth.
* A small number of countries account for a large share of global remittance inflows.
* Regional disparities exist in remittance distribution.
* Economic indicators such as GDP and population influence remittance trends.
* Several outliers are present due to exceptionally large remittance-receiving economies.

-> How to Run:-

1. Install dependencies:
pip install -r requirements.txt

2. Run the visualization script:
python visualization.py

3. Generated visualizations will be saved inside the images folder.
